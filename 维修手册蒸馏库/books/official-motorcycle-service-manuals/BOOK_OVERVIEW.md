## 本轮研究问题

1. 学徒接车后，怎样按“车型确认—安全检查—症状复现—系统分区—由外到内”的顺序定位故障？
2. 踏板、巡航和 ADV 的定期保养项目、检查方法及换件判据如何组织成可执行工单？
3. 发动机、CVT/传动、供油/电喷、冷却、制动/ABS、悬挂转向、电气系统分别有哪些标准诊断路径？
4. 怎样把扭矩、间隙、容量、磨损极限、故障码等车型数据做成“可查但不串用”的参数索引？
5. 维修完成后怎样执行复装确认、静态检查、动态验证和交车记录，形成质量闭环？

## 1. 结构（Structural）

### 类型

面向售后技师的实操手册合集。它不是从原理到实践循序渐进的教材，而是围绕具体车型提供维修准备、技术数据、拆装、检测、故障诊断和复检要求。

### 一句话主旨

摩托车维修不是凭经验直接拆换零件，而是在确认正确车型与版本后，按安全前置、规定周期、测量数据、拆装顺序、标准/极限和复检闭环执行。

### 整库骨架

1. **适用性与维修准备**：车型/工厂型号、发动机型号、年款、VIN、专用工具、安全警告和耗材要求。
2. **定期维护基线**：保养周期、油液、滤芯、火花塞、传动、制动、轮胎、紧固件和日常检查。
3. **动力与供给系统**：发动机机械、润滑、冷却、燃油、进排气、点火、电喷与排放控制。
4. **底盘与传动系统**：踏板 CVT、离合/变速、车轮、悬挂、转向、制动、ABS/TCS 与车身覆盖件。
5. **电气与诊断系统**：电源、充电、起动、传感器、执行器、线束、故障码、诊断接口和电路图。
6. **拆检与判定系统**：规定拆卸顺序、清洁、测量、标准值、使用极限、修复/更换判定、紧固扭矩和装配标记。
7. **维修质量闭环**：复装确认、排气/补液、静态功能检查、故障码清除、路试和维修记录。

**关系**：1–2 是所有工单的前置条件，3–5 是并列的系统维修域，6 是贯穿各系统的操作规则，7 负责把维修结果闭环。

### 厂方试图解决的核心问题

让具备基本机械和电气能力的维修人员，能在正确车型版本上，以规定工具、顺序和数据完成保养、拆装、检测、故障定位及安全复检，并降低误装、误判和二次损坏。

### 来源权威层级

| 资料类型 | 主要用途 | 权威边界 |
|---|---|---|
| 具体车型整车维修手册 | 整车拆装、维护、底盘、电气和故障流程 | 对应车型/年款内优先级最高 |
| 对应发动机维修手册 | 发动机内部结构、测量、极限与装配 | 只按发动机型号匹配，不能只按排量匹配 |
| 电路图/诊断资料 | 线束、端子、故障码和诊断条件 | 必须核对 ECU/ABS 供应商和软件/线束版本 |
| 零件图册 | 总成层级、零件位置和装配关系 | 不能代替维修步骤、扭矩和检验标准 |
| 赛用手册 | 特定赛用版本的维护与设定 | 不自动适用于民用/国内版车型 |

## 2. 解释（Interpretive）

### 关键术语（手册中的用法）

| 术语 | 手册中的操作性定义 | 容易混淆之处 |
|---|---|---|
| 车型/工厂型号 | 决定整车结构、线束、参数和零件适用性的精确标识，如 QJ300-12A | 商品名或排量相同不等于型号相同 |
| 标准值 | 新件或正常状态下的目标测量范围 | 不是“超过就必须换”的唯一边界 |
| 使用极限/维修极限 | 零件允许继续使用的最后判据，达到或超过通常应更换 | 不能拿另一发动机或年款的极限套用 |
| 拧紧扭矩 | 指定紧固位置、螺纹状态和装配条件下的目标扭矩 | 不是同直径螺栓都能共用的通用数值 |
| 检查（I） | 按规定方法检查，必要时清洁、调整、润滑或更换 | 不等于“看一眼没问题” |
| 更换（R） | 到达周期、极限或失效条件后换新 | 周期换件和状态换件应区分 |
| 上止点（TDC） | 活塞行程基准位置，用于配气、正时和间隙检查 | 压缩上止点与排气上止点不能混淆 |
| 总跳动（TIR） | 旋转件在百分表测量下的最大摆差 | 需要规定支撑、测点和转动方法 |
| DTC/故障码 | 控制器在满足检测条件时记录的异常线索 | 它指向电路/系统，不等于直接宣判零件损坏 |
| 当前故障/历史故障 | 当前仍满足触发条件的异常，与曾发生但现已消失的记录 | 清码不能代替修复和复现验证 |
| 诊断前提条件 | 电压、温度、转速、钥匙状态等故障检测成立所需工况 | 条件不满足时“无故障码”不能证明系统正常 |
| 专用工具 | 厂方为固定、测量、拆装或诊断规定的工具/适配器 | 用替代工具时必须评估精度和损伤风险 |

### 核心命题（用自己的话）

1. 所有维修数据先受车型、年款、发动机型号和 VIN 约束，再谈具体数值。
2. 接车诊断应先确认症状和基础条件，再进入部件级拆检，避免无证据换件。
3. 定期维护是故障预防系统，不只是换机油；它还包含检查、调整、润滑、紧固和记录。
4. 拆卸过程本身是诊断的一部分，零件方向、垫片顺序、磨痕、油迹和线束走向都要保留证据。
5. 零件能否继续使用，应由测量方法、标准值、维修极限和损伤形态共同决定。
6. 复装需要同时满足清洁、润滑、密封、标记、顺序和扭矩要求；只“装回去”不算完成。
7. EFI、ABS 等电控故障优先验证电源、搭铁、线路、接插件、传感器输入和前提工况，不应直接拆修控制模块。
8. 故障码是定位线索而不是零件更换指令；清码后必须复现工况并确认不再出现。
9. 制动、转向、轮胎、轮轴、悬挂和燃油系统属于安全关键域，维修后必须有独立复检。
10. 官方手册自身也承认产品持续改进，印刷版本可能落后，因此技术通报和门店系统版本必须参与最终判断。

### 论证链

各手册采用“系统结构/工作原理 → 规格与工具 → 拆卸 → 检查测量 → 维修或更换判定 → 装配 → 故障排查”的重复结构。厂方通过剖视图、零件位置图、测量方法、标准/极限表、扭矩表、故障码表和流程图，把经验维修转化为可重复操作。跨品牌的一致结构说明这套逻辑可以提炼成通用技师方法；但具体参数与连接定义仍必须留在车型数据层。

### 代表性来源锚点

- 凯越 `450RALLY_维修手册_英文.pdf`：PDF 第 2–4 页明确说明其用途、20 章结构及车型适用边界。
- 钱江各 RMI 手册：开篇列出车型工厂型号、年份、缩写、排放系统和版本变更声明；正文包含规格、拆装、EFI/ABS 与电气诊断。
- 升仕 `703F_2024与2026维修手册.pdf`、`703T_2026维修保养手册.pdf`：包含车辆信息、保养周期、扭矩、管线/电器布局、故障码和系统维修。
- 升仕 `368踏板_ZT1P79MP发动机维修手册.pdf`：独立覆盖发动机内部拆检与装配，不能由整车踏板手册完全替代。

## 3. 批判（Critical）

### 时代与版本局限

- 资料主要是 2022–2026 年的公开版本；同名车型后续可能改变 ECU、ABS、线束、传感器、紧固件或零件号。
- 钱江 RMI 手册使用海外商品名和英文版本，国内闪系/鸿系必须依靠公告型号和 VIN 判断是否同构。
- 凯越公开资料集中在 450 Rally，800X 只有零件图册；525X、625X、800X 国内版不能据此推定完整维修数据。
- 奔达灰石目前没有进入本合集，因为厂方官网未公开技师维修手册；用户手册不能补足拆装和诊断数据。

### 厂方立场盲点

- 手册默认读者具备机械、电气、安全和量具使用基础，并可能拥有专用工具、诊断仪和门店软件；它没有完整教授这些前置能力。
- 厂方文件按单一车型组织，不负责帮学徒建立跨车型知识结构，重复内容多、学习顺序不友好。
- 部分英文译文和表格排版不自然，术语可能存在翻译误差；关键动作应同时核对图示、上下文和实车。

### 未被证明的假设

- “按手册操作即可完成维修”隐含工具精度、工作环境、配件质量和操作者基本技能都合格。
- “故障现象可稳定复现”在间歇性线束、热衰退、通信或软件故障中常常不成立。
- “维修参数在同一车型名下稳定”可能被生产批次和供应商变更打破。

### 文本抽取局限

- 38 份资料可全文检索；3 份辐条长度图只有 86–130 个字符，必须直接查看图面。
- 旋转表格、接线图、爆炸图和图中标注可能无法完整抽取。
- 任何扭矩、间隙、容量、针脚或故障码结论都必须保留“文件 + PDF 页码”，必要时目视复核原 PDF。

### 最强反对意见

把多车型官方手册合并成“通用知识”会提高误用参数的风险；如果蒸馏结果不能强制显示适用车型和原始页码，那么它可能比直接查原手册更危险。因此后续必须把“通用工序”和“车型参数”分层：前者可复用，后者只能查询、不能跨车型推理。

- [ ] ABS/制动系统安全诊断与维修后验证
- [ ] 踏板 CVT 检查、磨损判断和复装流程
- [ ] 发动机压缩、配气、正时、润滑和冷却的分层诊断
- [ ] 充电、起动、点火和线束故障的电气测量流程
- [ ] 静态检查—路试—交车记录的闭环复检

### 不适合直接 skill 化的内容

- 具体车型的整张扭矩表、间隙表、容量表和故障码表：应做成带来源约束的数据卡，而不是通用规则。
- 电路图、爆炸图和辐条图：应保留为视觉附件并建立定位索引，不能只靠文字重述。
- 单一赛用设定、宣传性说明和版权声明：保留审计价值，但不独立形成技能。

### 预估 skill 数量

约 **8–12 个跨车型可执行模块**，另配 **按车型隔离的数据卡与来源索引**。最终数量由阶段 1.5 的跨段落佐证、预测力和独特性验证决定。

### 优先级排序

1. 车型适用性门禁与高风险参数防串用。
2. 接车诊断、基础检查和故障树。
3. 周期保养工单与维修后复检。
4. 钱江踏板/CVT 与巡航底盘、电气维修。
5. 升仕踏板、ADV、发动机及 EFI/OBD 诊断。
6. 凯越 450 Rally 整车维修与 800X 总成识别。
7. 低频深度发动机大修和赛用维护。
