# 官方维修手册共享术语表

> 用于统一 12 个技师能力模块中的概念。具体数值、针脚、液体规格和程序仍以对应车型原 PDF 为准。

| 术语 | 在本资料集中的精确定义 | 容易混淆之处 | 主要来源 |
|---|---|---|---|
| 适用车型/版本 | 手册能直接用于判断的车型、年款、排放版和配置边界 | 不是商品名或排量相同就通用 | 703F第2页；ATR125第29页 |
| 标准值 | 新件、正常件或规定工况下的健康基准 | 不是报废线 | ATR125第20页；368发动机第10页 |
| 维修极限 | 厂方允许继续使用的最后边界 | 不是推荐的新件尺寸 | 同上 |
| 配合间隙 | 两个配合件实测尺寸之差 | 不能只量其中一件 | SRV700第291页；368发动机第24页 |
| 最不利值 | 多方向/高度/圆周测量中的最大磨损、跳动或最小余量 | 不能用平均值掩盖局部失效 | 368发动机第13页；ZT370MU第53页 |
| 故障码 DTC | 控制器记录的电路、信号或系统异常线索 | 不是坏件判决书 | 703F第86-87、97页 |
| 当前故障 | 测试时仍满足监测异常条件的故障 | 与历史/偶发故障分开 | ATR125第115页 |
| 历史/偶发故障 | 曾被记录、此刻可能未满足报码条件的异常 | 当前无报码不等于从未发生 | LTM125第363页 |
| 诊断前提门禁 | 解释测试前必须满足的电压、搭铁、保险、压力、连接与工况 | 不是可跳过的准备工作 | MTX125第161页；703F第84页 |
| 燃油压力 | 规定工况下油泵、滤网、调压和管路共同形成的压力 | 油泵有声不等于燃压合格 | 450 Rally第122页；ATR125第179页 |
| ECU/ECM | 接收传感器信号并控制喷油、点火和执行器的发动机控制单元 | 不是电喷故障的默认换件对象 | SRV300第176页；703F第97页 |
| 连续性/开路/短路 | 预期导通、路径中断、与非预期电源/搭铁/回路相连 | 插头外观正常不能替代万用表验证 | 703F第97页 |
| ABS液压控制单元 | 集成泵、阀体和控制的防抱死核心部件 | ABS正常不证明基础制动正常 | LTM125第182页；450 Rally第51页 |
| 制动排气 | 持续补充合规液体并按序排出空气，直到无气泡且手感稳定 | 不是松一次放气螺钉 | 450 Rally第50页；703F第59页 |
| CVT | 主动盘、滚子、皮带、从动盘、离合器和终传组成的无级传力链 | 不是单指一条皮带 | ZT1P77MP第33页；150T-M/D第29页 |
| 传动带维修极限 | 对宽度、裂纹、缺齿和损伤检查后决定继续使用或更换的边界 | 不能只按里程或肉眼判断 | ATR125第63页 |
| TDC/正时上止点 | 活塞在规定相位的最高位置，曲轴与凸轮标记同时符合手册 | 活塞最高点不一定是压缩上止点 | ZT370MU第21页 |
| 气门间隙 | 指定温度和正时位置下气门机构配合面的间隙 | 不是任意曲轴位置的缝隙 | ZT184MP第13页；ZT370MU第40页 |
| 配对/分组零件 | 因原位磨合或制造尺寸组而必须保持对应关系的零件 | 同名同排量不等于可以互换 | SRV550ST第13页；ZT184MP第21页 |
| 静态验收/动态复验 | 前者是移动前的安装与功能门禁；后者按原触发条件运行或路试 | 路试不能替代静态安全检查，清码不能替代复验 | 450 Rally第7页；LTR125第154页 |
