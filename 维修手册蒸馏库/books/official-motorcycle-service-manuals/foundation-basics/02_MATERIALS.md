# 2.2.2 摩托车常用材料

## 学习目标

- 能读懂燃油、润滑油、冷却液和轮胎的主要规格标识。
- 能区分常见轴承结构及其承载方向。
- 知道材料选择错误、混用和污染会造成什么后果。
- 形成“按手册规格选材，不凭颜色和手感猜测”的习惯。

## 一、燃油的标号、性能与应用

汽油标号主要反映抗爆震能力，不等于清洁度、能量密度或“动力等级”。发动机所需标号由压缩比、燃烧室、点火控制、增压情况和标定决定。使用低于要求的燃油可能引发爆震、退点火和过热；盲目提高标号通常不会自动增加功率。

维修时至少核对：手册要求的辛烷值表达方式、是否允许乙醇汽油、燃油存放时间、油箱污染和用户是否混入其他液体。长期存放的燃油可能挥发、氧化并形成胶质，含醇燃油还可能吸水分层。

安全要求：燃油区域保持通风，远离火焰、火花、热表面和产生电弧的开关；泄压和拆管前按手册执行；使用合格容器回收，禁止用嘴吸油或用汽油清洗零件。

## 二、润滑油、润滑脂和防冻液

### 发动机油

- 粘度等级描述低温流动和工作温度下的粘度范围，不代表质量等级。
- API 等质量等级与发动机设计、排放和油品性能有关。
- 湿式离合器摩托车通常还要关注 JASO MA 或 MA2；部分踏板车可能使用适合其结构的 MB 等级。必须按车型手册选择。
- 四冲程发动机油与二冲程燃烧型润滑油用途不同，不可互代。

换油时要同时核对油量条件、滤芯、放油螺栓密封件、检查姿态和油位读取方法。加得过多也可能造成曲轴搅油、通气系统带油和功率损失。

### 润滑脂

润滑脂由基础油、稠化剂和添加剂组成。轴承脂、防水脂、高温脂、橡胶兼容脂和电气绝缘脂用途不同。不同稠化体系可能不相容，混合后会变稀、变硬或析油。制动摩擦面、轮胎和传动带不得沾脂。

### 冷却液与防冻液

冷却液承担防冻、防沸、防腐、润滑水泵密封和传热。颜色不是可靠规格；相同颜色可能配方不同，不同颜色也可能兼容。应核对原厂要求、浓度、是否预混和更换周期。

浓缩液若需兑水，应按产品与手册要求使用合适水质；随意增加浓度并不会无限提高冷却能力。热车时不得直接打开承压水箱盖。

## 三、摩托车轮胎

### 结构和用途

- 斜交胎胎体帘线交叉，侧壁与胎面整体变形特性明显。
- 子午线胎帘线径向排列，通常配合带束层，适用于较高速度和热负荷设计。
- 有内胎和无内胎结构必须与轮辋、气门嘴及原设计匹配。
- 公路、巡航、运动、踏板、越野和多用途轮胎的花纹、胎体与胶料取向不同。

### 规格读取示例

以 `120/70 ZR17 M/C 58W TL` 为例：120 为名义断面宽度毫米数；70 为扁平比；ZR 表示适用于相应高速范围的子午线结构；17 为轮辋名义直径英寸数；M/C 表示摩托车用；58 是负荷指数；W 是速度级别；TL 表示无内胎。

实际选胎还要核对前后轮位置、允许轮辋宽度、旋转方向、负荷和速度等级。不能只因“装得上”就改变宽度、扁平比或结构，因为这会改变轮胎外径、轮廓、转向、车身高度、ABS 轮速关系和间隙。

胎压按车辆制造商规定并在指定温度条件下检查，不把胎侧最大压力当作日常推荐胎压。发现鼓包、帘线外露、严重龟裂、扎伤位置不适合修补或气密层损伤时，应按安全标准处理。

## 四、轴承的种类与结构

- **深沟球轴承**：结构常见，可承受径向载荷及一定双向轴向载荷，常用于车轮、变速机构和电机。
- **角接触球轴承**：适合组合承受径向与单向轴向载荷，安装方向和预载重要。
- **圆锥滚子轴承**：可承受较大的径向与轴向组合载荷，常见于部分转向柱或轮毂结构，需要正确配对和调整。
- **滚针轴承**：径向尺寸小、承载能力高，常见于连杆小头、摆臂或齿轮支承。
- **圆柱滚子轴承**：适合较高径向载荷，部分结构允许轴向位移。
- **止推轴承**：主要承受轴向载荷。
- **滑动轴承或衬套**：依靠油膜或低摩擦材料工作，对润滑、间隙和表面状态敏感。

轴承由内圈、外圈、滚动体、保持架及可能存在的密封或防尘盖组成。拆装时应把力施加在与配合面相对应的套圈上，不能让安装力通过滚动体传递。检查项目包括异响、卡滞、粗糙感、游隙、变色、剥落、锈蚀和配合面松动。

## 五、其他常用材料

- **钢、铝合金和镁合金**：重量、强度、刚度、耐腐蚀和热膨胀不同，紧固和修复工艺不能一概而论。
- **铜与铜合金**：常用于导电件、衬套和密封垫；一次性压溃垫按手册换新。
- **橡胶和弹性体**：用于油封、O 形圈、软管和减振件。燃油、制动液、机油和冷却液对材料兼容性要求不同。
- **工程塑料与复合材料**：用于外壳、连接器、导流件和摩擦材料；受热、溶剂或错误紧固可能开裂。
- **螺纹锁固剂、密封剂和装配剂**：颜色不能作为唯一型号依据。使用位置、强度、固化条件、涂布量和拆卸方式必须按手册。
- **摩擦材料**：制动片和离合器片依靠受控摩擦工作，严禁沾油；更换后按要求磨合并复验。

## 材料选择的维修原则

1. 先读零件号、手册规格和产品技术说明，再看颜色或包装习惯。
2. 不确定兼容性时不混用，不用“差不多”的材料完成安全关键维修。
3. 油液取样要使用清洁容器，防止把外界污染误判为系统内部故障。
4. 记录品牌、规格、批次、用量和更换日期，便于复查。

## 练习与自测

1. 找三条不同轮胎规格，逐项解释宽度、扁平比、结构、轮辋、负荷和速度标识。
2. 比较湿式离合器摩托车油与普通乘用车油的选用关注点。
3. 用废旧轴承识别内外圈、滚动体、保持架和密封，并说明压装受力位置。
4. 回答：为什么冷却液不能仅凭颜色判断能否混用？
